Kelime Sihirbazı

Bu proje, kelime ezberleme sürecini verimli hale getirmek amacıyla geliştirilmiş bir Android uygulamasıdır. Proje; veritabanı yönetimi, veri analitiği ve kullanıcı deneyimi prensipleri dikkate alınarak tasarlanmıştır.

Proje Özellikleri
- Kategorize Edilmiş Veri Yönetimi: Kelimelerin konularına göre saklanması ve düzenlenmesi.
- Sınav Modu: Öğrenilen kelimelerin pekiştirilmesi için soru-cevap tabanlı test mekanizması.
- Performans Analizi: Konu bazlı başarı yüzdelerinin hesaplanarak kullanıcıya istatistiksel geri bildirim sunulması.
- Veri Dışa Aktarma:Analiz sonuçlarının cihaz üzerindeki paylaşım protokolleri aracılığıyla raporlanabilmesi.

Teknik Uygulama
- Geliştirme Ortamı: Android Studio / Java
- Veri Depolama: SQLite 
- Hata Yönetimi: Uygulamanın çalışma kararlılığını artırmak adına kritik veri işlemlerinde hata yakalama mekanizmaları kurgulanmıştır.
- Mimari: Modüler yapı sayesinde veritabanı ve arayüz katmanları birbirinden ayrılmış, sürdürülebilir bir kod yapısı hedeflenmiştir.
